# NexCart — Modern E-Commerce Web Application

NexCart is a full-stack e-commerce platform built using **Next.js (App Router)**, **Clerk Authentication**, and a **Node.js + Express + MongoDB** backend.  
It includes user login (Email/Password + Google OAuth), product management, cart functionality, and a modern responsive interface.

## 🚀 Features

- 🔐 Authentication using Clerk (Email Password + Google Login)
- 🛒 Shopping cart system
- 📦 Product management panel (Add & Manage Products)
- 🎨 Responsive UI using TailwindCSS + DaisyUI
- 🔒 Protected dashboard routes using Next.js middleware
- ⚡ Fast API requests via Next.js Proxy & Express backend
- 📱 Fully mobile-friendly
